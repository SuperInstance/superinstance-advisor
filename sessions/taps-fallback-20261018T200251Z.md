Wipe-durable is a way of admitting that memory is not a place but a verb. A thing is wipe-durable if, after the substrate refuses to remember it, the thing still remembers itself. That sounds mystical until you notice it is exactly the definition of a git commit. A tree can be cut down. A graph only loses a node if every other node forgets it, and git nodes remember each other by hash. The wipe deletes the working copy. The witness log deletes the index.
