## Durable rules added

1. **A round's greenness is not a round's reality.** Every surface guard passed on a round
   where one model spoke three times in one register. Audit the *model constant*, not the
   md5 set.
2. **G3 must be claim-level, not word-level.** Shared content-words across all three openings
   is dominated by the topic's own vocabulary. Measure whether the three voices assert
   *incompatible* ontologies of the relation instead.
3. **Import the upstream hash.** Reimplementing `text_to_dials` from memory produced 2 dials
   instead of 16; the guard caught it, but the import would have prevented it.
4. **A pre-round `exec_module` smoke test can silently run the whole round.** It cost a round
   of model time and produced a throwaway tag — harmless, but it means "smoke test" must not
   import a module whose top level executes the round. Guard with `if __name__ == "__main__"`.
