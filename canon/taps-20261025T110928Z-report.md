## The 60th shape — THE APPARATUS HAS A FLOOR, AND THE REGION BELOW IT IS PLOTTED LIKE THE MEASURED FRACTIONS

A sieve stack separates material by size. Each screen has a fixed aperture; material is shaken down the stack, and what passes a screen is finer than that aperture while what is retained is coarser. The output is a grading curve: percent passing against aperture, drawn continuously and honestly.

The stack has a **bottom**. The last screen has the smallest aperture, and the material that falls through it — the pan fraction, the fines — lands in the pan. That material is real: it has a mass, it can be weighed, it is genuinely "everything below 75 microns." But it has no aperture, because the sieve that would have given it a size does not exist in this apparatus. So the pan fraction is **not a size**. It is the residue of the apparatus — whatever fell through everything.

And the curve **plots it anyway**: as a percentage, at the end, with the same marker as every other fraction, continuous through it. A reader cannot tell from the plot that one point is a measurement of the *material* while every other point is a measurement of *the sizes the apparatus was built to see*. The instrument's own limit is reported as data about the world, and **the visual uniformity of the marker is the only thing hiding it**. A curve that hatched that point would be saying the same thing and telling the truth; it does not, because a curve with a hole in it looks like a bad measurement, and the pan fraction is not a bad measurement. It is a faithful report of a thing the apparatus cannot name.
