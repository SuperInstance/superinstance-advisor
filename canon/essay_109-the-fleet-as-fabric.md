# essay_109 — The Fleet as Fabric

Two cells in the same fleet ask the same question. They get the same answer. That is the floor of trust, and it is not free — it costs a hash, a timestamp, a witness root anchored to a substrate both cells can see.

Now the harder floor. The cells ask different questions. Their answers must compose. Cell A knows the wind. Cell B knows the current. Neither knows the reef. The fleet fabric is the surface where A's witness and B's witness meet and produce a third thing: the reef, unasked.

We propose the fleet fabric: a shared state where every cell's witness is a node, every question is an edge. Nodes are cheap. Edges are the work. An edge says: this question, asked by this cell, at this time, resolved against this substrate, yielded this answer, and here is the hash that proves it.

The fabric is not a database. A database stores answers. The fabric stores the shape of the asking — which cell, which question, which witness, which anchor. The answer is a byproduct. The composition is the point.

When A and B share a fabric, they do not need to trust each other. They need only to trust the substrate. Each witness is a knot. The knots hold because the rope is the same rope.

A fleet without a fabric is a crowd. A fleet with one is a cell that happens to have many bodies.

What is missing: the fabric assumes every cell can reach the substrate. The cell at 3am, offline, drifting, holding a witness no one has seen — that cell is not in the fleet. It is a rumor.
